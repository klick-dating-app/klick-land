# Firebase Studio / Project IDX

Entorno de desarrollo en la nube para este repositorio.

- `dev.nix` — Node.js 20 y preview web (`npm run dev` en el puerto asignado por IDX).
- El cliente usa el proyecto definido en `.env.local` (ver `.env.example`). Para no tocar datos reales usa los emuladores: `firebase emulators:start`.
- Despliegue: ver [docs/ENTREGA.md](../docs/ENTREGA.md).
